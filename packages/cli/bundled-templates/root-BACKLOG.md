# Backlog

Human-maintained follow-ups for this repo. **Not** session goals (those stay in chat per `.agent/phases/developing.md`). Completed work moves to **`LOGBACK.md`** via `/daf-backlog-work`.

## Conventions (markdown mode)

Each open item is one line under **`## Open`**:

```markdown
- [ ] #p2 #feature Short description of the work
```

| Token | Meaning |
|-------|---------|
| `#p1` | Do soon — blocks or high impact |
| `#p2` | Normal priority (default if omitted) |
| `#p3` | Nice-to-have / when time allows |
| `#feature` | Net-new capability (`/daf-new-feature`) |
| `#bug` | Defect (`/daf-issue`) |
| `#polish` | Improve existing (`/daf-improvement`) |
| `#pivot` | Redesign (`/daf-pivot`) |
| `#keep` | On logback close: never auto-prune the LOGBACK entry |

Sort within **Open** by priority (`#p1` first). `/daf-backlog-work` may pick highest priority when the user does not specify.
