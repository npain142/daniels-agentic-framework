# Skill: /daf-retro

**When:** After any non-trivial task.

For explicit user rules the agent should always follow, use `/daf-remember` → `memory/remember.md` instead of retro.

## Steps

1. Ask: what surprised us, what should we never do again, what should we codify?
2. Propose ≤3 lines total for `.agent/memory/learnings.md` and/or `.agent/memory/gotchas.md`.
3. Wait for user approval before writing files (unless user asked to apply retro).

## Stop condition

Concise proposals exist; optional file append after approval.
