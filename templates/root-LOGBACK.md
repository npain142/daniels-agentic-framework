# Logback

Fading long-term memory from **completed** backlog items. Agents may read for context on related work. Not a task list.

**Prune** (automatic on `/daf-backlog-work` close): entries **without tags** older than **7** days; entries **with tags** older than **14** days; entries with **`#keep`** are never auto-pruned.
